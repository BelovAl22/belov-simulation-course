### Система массового обслуживания M/M/1/0 с периодическими поломками
Моделирование одноканальной СМО с отказами (без очереди) и учетом надежности оборудования.

## Используемые параметры
 
| Параметр | Значение | Описание |
|---|---|---|
| λ | 2,0 | Интенсивность поступления заявок |
| μ | 3,0 | Интенсивность обслуживания |
| N | 1000 | Количество моделируемых заявок |
| T_раб | 200,0 | Интервал между поломками (ед. времени) |
| T_рем | 20,0 | Длительность ремонта (ед. времени) |
| Seed | Ticks | Зерно генератора (системное время) |

## Результаты моделирования
 
| Характеристика | Эмпирическое значение | Теоретическое значение (без поломок) |
|---|---|---|
| Коэффициент загрузки ρ | 0,6667 | λ/μ = 0,6667 |
| Вероятность простоя P₀ | ~0,5540* | 1/(1+ρ) = 0,6000 |
| Вероятность занятости P₁ | ~0,3550* | ρ/(1+ρ) = 0,4000 |
| Вероятность отказа P_отк | ~0,4460* | P₁ = 0,4000 |
| Количество поломок | 2–3 | — |
 
*\* Примечание: Эмпирические значения могут варьироваться в зависимости от прогона модели. Вероятность отказа выше теоретической из-за простоя системы во время ремонта.*

## Выводы
 
1. **Влияние поломок на характеристики системы.** В ходе моделирования было выявлено, что наличие периодических поломок (каждые 200 ед. времени на 20 ед. времени) увеличивает реальную вероятность отказа $P_{отк}$ по сравнению с классической моделью M/M/1/0. Это объясняется тем, что в периоды ремонта прибор недоступен для обслуживания, и все поступающие заявки получают отказ, даже если до этого канал был свободен.

2. **Отклонение от теоретических значений.** Теоретические формулы Эрланга для $P_0$ и $P_1$ в данном случае служат лишь "идеализированным" ориентиром. На практике вероятность занятости канала $P_1$ снижается, так как часть времени прибор находится в состоянии "ремонт", а не "обслуживание". Суммарная вероятность состояний в модели распределяется между тремя фазами: простаивает, занят, сломан.

3. **Анализ пропускной способности.** При заданных параметрах ($\lambda=2, \mu=3$) и коэффициенте технического использования прибора (около 91% времени прибор исправен), система теряет около 44-46% входящего потока заявок. Без поломок этот показатель составлял бы ровно 40%.

4. **Корректность программной реализации.** Имитационная модель построена на методе "следующего события", что позволило точно зафиксировать моменты поломок и прерывания обслуживания. Использование экспоненциального распределения для интервалов прихода и времени обслуживания подтверждается характером распределения результатов вокруг теоретических средних.
