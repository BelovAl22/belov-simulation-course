### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.
4. Сбор статистики и всей необходимой информации в .txt или .csv формат (.csv формат предпочтительней)

### Используемые алгоритмы и математическая модель
Моделирование реализовано на основе **непрерывной цепи Маркова (СТМС)**. Процесс описывается матрицей интенсивностей $Q$, где внедиагональные элементы $q_{ij}$ — это интенсивности переходов, а диагональные $q_{ii} = -\sum_{j \neq i} q_{ij}$ характеризуют суммарную интенсивность выхода из состояния.

1.  **Расчет времени пребывания:** Длительность нахождения в текущем состоянии $i$ является случайной величиной, распределенной по экспоненциальному закону. Она вычисляется по формуле:
    $$\Delta t = -\frac{\ln(u)}{\lambda_i}$$
    где $u$ — случайное число из диапазона $(0, 1)$, генерируемое стандартным датчиком (основанным на линейном конгруэнтном методе), а $\lambda_i = -q_{ii}$.
2.  **Выбор следующего состояния:** После истечения времени $\Delta t$ происходит переход в состояние $j$ с вероятностью $p_{ij} = \frac{q_{ij}}{\lambda_i}$.
3.  **Теоретический расчет:** Стационарные вероятности $\pi = (\pi_1, \pi_2, \pi_3)$ находятся из системы линейных уравнений:
    $$\begin{cases} \pi Q = 0 \\ \sum \pi_i = 1 \end{cases}$$
    Решение системы в программе реализовано **методом Крамера** для матрицы 3x3.

Программная реализация выполнена на языке **C# (WinForms)** и включает:
*   **Редактор матрицы $Q$:** Позволяет задавать произвольные интенсивности.
*   **Управление симуляцией:** Выбор условия остановки (по количеству шагов или по количеству модельных дней), а также слайдер для регулировки скорости визуализации (Delay).
*   **Визуализация:** Круговая диаграмма (Chart), отображающая доли времени, проведенного в каждом состоянии, и RichTextBox для подробного логирования переходов с указанием времени в формате [день:часы].
*   **Статистика:** Автоматическое сравнение накопленных данных с теоретическим расчетом в реальном времени.

### Вывод
В ходе работы была реализована имитационная модель погодных условий. В отличие от дискретных цепей Маркова, данная модель учитывает, что время нахождения в каждом состоянии случайно. Экспериментально подтверждено, что при увеличении времени моделирования или количества событий эмпирическое распределение стремится к теоретическому стационарному распределению, что подтверждает корректность алгоритма и математической модели.
