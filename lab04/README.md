### Базовый датчик случайных чисел

**Задание:**
- реализовать базовый датчик случайных чисел;
- вычислить выборочные среднее и дисперсию:
  - для реализованного датчика;
  - для встроенного генератора языка программирования;
- размер выборки — **100 000 значений**;
- сравнить результаты с теоретическими;
- сделать вывод.

---

Реализован мультипликативный конгруэнтный генератор (MCG) с параметрами:
- **M = 2147483647**
- **a = 16807**
- **c = 0**

## Результаты (выборка: 100 000 значений)
seed = 4567

## Заключение

1. Реализованный мультипликативный конгруэнтный генератор (MCG) формирует последовательность псевдослучайных чисел, статистические характеристики которой близки к теоретическим значениям для равномерного распределения на интервале U[0,1).
2. Выборочные среднее и дисперсия, вычисленные по выборке объёма 10⁵, демонстрируют малые отклонения от теоретических значений (0.5 и 1/12 соответственно), что подтверждает корректность реализации генератора и методов статистической оценки.
3. Встроенный генератор языка C# (Random) показывает практически одинаковые результаты, не смотря на использование более сложных алгоритмов генерации, обеспечивающих в теории лучшее качество псевдослучайной последовательности.
4. Отклонения в MCG <0,001 для среднего и <0,1 для дисперии. Подобные результаты  показывает и Random(). 
5. MCG с параметрами Парка–Миллера обеспечивает приемлемое качество генерации.

**Итог:** Реализованный мультипликативный конгруэнтный генератор является простым и эффективным методом генерации псевдослучайных чисел
