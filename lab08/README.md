# Пуассоновский поток. События на сервере

Моделирование потока заявок на сервер.

**Задание:**

* событие — поступление заявки;
* определить число заявок за интервал времени $T$;
* построить распределение числа заявок;
* вычислить среднее и дисперсию;
* сделать вывод.

## Описание проекта

Программа моделирует поток заявок на сервер с использованием свойств простейшего пуассоновского потока. Приложение разработано на платформе **Windows Forms (.NET Framework 4.7.2)** и позволяет проводить серию статистических экспериментов с заданными параметрами интенсивности потока и времени наблюдения.

В ходе работы реализован самописный генератор псевдослучайных чисел, выполнено статистическое моделирование $N$ экспериментов, построена гистограмма эмпирического распределения числа заявок и вычислены основные статистические характеристики моделируемого процесса.

## Используемые параметры моделирования

| Параметр       | Значение | Описание                                                           |
| -------------- | -------- | ------------------------------------------------------------------ |
| **λ (Лямбда)** | 5        | Интенсивность потока (среднее количество заявок в единицу времени) |
| **T**          | 2        | Интервал наблюдения за сервером                                    |
| **N**          | 1000     | Количество независимых экспериментов                               |
| **Seed**       | 10       | Начальное значение генератора MCG                                  |

---

## Реализация модели

### 1. Генератор случайных чисел

Для получения равномерно распределённых случайных величин $u \in (0,1)$ использован **мультипликативный конгруэнтный генератор (MCG)**.

Параметры генератора:

* Модуль: $M = 2^{31} - 1$
* Множитель: $\beta = 48271$
* Начальное значение: $Seed = 10$

Формула генерации:

$$
x_{i+1} = (x_i \cdot \beta) \pmod M
$$

Полученное значение нормируется к интервалу $(0,1)$:

$$
u_i = \frac{x_i}{M}
$$

### 2. Моделирование потока заявок

В простейшем пуассоновском потоке интервалы между соседними событиями имеют экспоненциальное распределение.

Для генерации времени между поступлениями заявок используется метод обратной функции:

$$
\tau = -\frac{1}{\lambda}\ln(u)
$$

где:

* $\tau$ — время до следующего события;
* $\lambda$ — интенсивность потока;
* $u$ — случайное число из интервала $(0,1)$.

В рамках одного эксперимента интервалы времени последовательно суммируются до тех пор, пока накопленное время не превысит заданный интервал наблюдения $T$.

Количество сгенерированных событий за время $T$ принимается за число заявок на сервер.

## Результаты моделирования

Для параметров:

* $\lambda = 5$
* $T = 2$
* $N = 1000$

теоретическое математическое ожидание и дисперсия распределения Пуассона определяются выражением:

$$
M[X] = D[X] = \lambda T
$$

Следовательно:

$$
M[X] = D[X] = 5 \cdot 2 = 10
$$

По итогам моделирования получены следующие результаты:

| Характеристика     | Эмпирическое значение | Теоретическое значение ($\lambda T$) |
| ------------------ | --------------------- | ------------------------------------ |
| **Среднее M[X]**   | 9,955                 | 10,0                                 |
| **Дисперсия D[X]** | 9,639                 | 10,0                                 |

1. **Подтверждение свойств распределения.** Для пуассоновского потока выполняется фундаментальное свойство:

$$
M[X] = D[X] = \lambda T
$$

Полученные эмпирические значения среднего и дисперсии близки к теоретическому значению 10, что подтверждает корректность реализации модели.

2. **Сходимость результатов моделирования.** При количестве экспериментов $N = 1000$ наблюдается хорошее совпадение эмпирических характеристик с теоретическими. Увеличение числа экспериментов приводит к дальнейшему уменьшению статистической погрешности.

3. **Корректность алгоритма.** Использование метода обратной функции для генерации экспоненциально распределённых интервалов времени и самописного мультипликативного конгруэнтного генератора позволило корректно смоделировать поток заявок на сервер.

4. **Практический результат.** Разработанное приложение позволяет исследовать свойства пуассоновского потока, анализировать распределение числа событий и сравнивать экспериментальные результаты с теоретическими характеристиками распределения Пуассона.
