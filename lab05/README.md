### Моделирование случайных событий (GUI)

**Часть 1:**  
Приложение «Скажи “да” или “нет”».

**Часть 2:**  
Приложение «Шар предсказаний» (Magic 8-Ball).

## Описание

В данной лабораторной работе реализовано моделирование случайных событий с использованием пользовательского генератора псевдослучайных чисел. Приложение разработано на платформе Windows Forms и включает два независимых модуля: «Да/Нет» и «Шар предсказаний».

В основе работы лежит мультипликативный конгруэнтный генератор (MCG), позволяющий получать последовательность псевдослучайных чисел в диапазоне [0,1). Генератор инициализируется начальным значением (seed = 67), которое может задаваться пользователем через графический интерфейс. Это обеспечивает воспроизводимость результатов моделирования.

## Распределения вероятностей

### Часть 1: «Да» / «Нет»

| Исход | Вероятность |
|-------|-------------|
| Да    | 0.50        |
| Нет   | 0.50        |

### Часть 2: Магический шар

| Ответ           | Вероятность |
| --------------- | ----------- |
| Да              | 0.20        |
| Нет             | 0.20        |
| Скорее да       | 0.15        |
| Скорее нет      | 0.15        |
| Не знаю         | 0.10        |
| Спроси позже    | 0.10        |
| Определённо да  | 0.05        |
| Определённо нет | 0.05        |

Суммарная вероятность равна 1, что обеспечивает корректность распределения.
